# Garage 11 — сайт автосервиса

Адаптивный одностраничный шаблон в светлом премиум-минимализме. Откройте `index.html` напрямую в браузере; сборка и установка пакетов не требуются.

## Содержание

- Услуги в раскрывающемся списке
- Четыре этапа обслуживания с анимированной линией
- Демонстрационные пакеты технического обслуживания
- Переключаемые цитаты-образцы
- Контакты, график и ссылка на карту

## Перед публикацией

Замените демонстрационные цены, номер телефона, адрес, часы работы и образцы отзывов на подтверждённые данные компании. Фотографии и шрифт загружаются с внешних сайтов и требуют подключения к интернету.

## Технологии

HTML, CSS и JavaScript без сборщика. Плавные появления, параллакс изображения, аккордеон и переключение цитат реализованы на нативном JavaScript/CSS; учитывается `prefers-reduced-motion`.
